# Satoshi Scramble

**GRAB. BANK. ESCAPE.** — a 4–8 player realtime loot-and-bank arena for the
Hashplay arcade. Real players share one arena; collected loot is not safe
until banked; the pot settles in **aBTC on Arch testnet**.

Status: **discovery complete** — see `docs/DISCOVERY.md`. Implementation has
not started (gated build order; architecture docs come next).

Standalone project — no dependency on the sibling CoinUp/Arch Duel repo,
which serves as reference and prior art only.
